# VR CPR Training and Assessment System

ชื่อโครงงาน:
VR CPR Training and Assessment System on PICO 4 using Microcontroller and Pressure Sensor

ที่มาและความสำคัญ

การช่วยฟื้นคืนชีพ (CPR) เป็นทักษะสำคัญในการช่วยเหลือผู้ที่เกิดภาวะหัวใจหยุดเต้นหรือหมดสติในสถานการณ์ฉุกเฉิน แต่การเรียนรู้จากเอกสารหรือวิดีโอเพียงอย่างเดียวอาจไม่เพียงพอต่อการสร้างทักษะในการปฏิบัติจริง ขณะที่การฝึกด้วยอุปกรณ์จริงอาจมีข้อจำกัดด้านสถานที่ อุปกรณ์ เวลา และจำนวนผู้ฝึก

โครงงานนี้จึงมีแนวคิดในการนำ Virtual Reality (VR) มาประยุกต์ใช้ร่วมกับอุปกรณ์ฝึก CPR เพื่อสร้างสถานการณ์จำลองที่ผู้ใช้งานสามารถมีส่วนร่วมและฝึกปฏิบัติได้จริง โดยใช้ PICO 4 เป็นอุปกรณ์แสดงสภาพแวดล้อมเสมือนจริง และใช้ ESP32 ร่วมกับ Pressure Sensor เพื่อตรวจจับการกดหน้าอกบนอุปกรณ์จำลอง จากนั้นส่งข้อมูลเข้าสู่ระบบ VR เพื่อประมวลผลและแสดงผลการฝึกแบบ Real-Time

อุปกรณ์และเทคโนโลยีที่ใช้
PICO 4 สำหรับแสดงสถานการณ์จำลองและการโต้ตอบใน VR
Unity Engine และ C# สำหรับพัฒนา VR Application
ESP32 สำหรับรับและประมวลผลข้อมูลจาก Sensor
Pressure Sensor สำหรับตรวจจับการกดหน้าอก
อุปกรณ์จำลองหน้าอก สำหรับใช้ในการฝึก CPR
OpenXR / PICO SDK สำหรับรองรับการทำงานของระบบ VR
Serial หรือ Wi-Fi Communication สำหรับรับส่งข้อมูลระหว่าง ESP32 และ Unity
การทำงานของระบบ

ผู้ใช้งานสวม PICO 4 และเข้าสู่สถานการณ์จำลอง เช่น การพบผู้หมดสติในสถานที่ต่าง ๆ ระบบจะแนะนำให้ผู้ใช้งานดำเนินการตามขั้นตอนที่กำหนดจนเข้าสู่การทำ CPR เมื่อเริ่มกดหน้าอกบนอุปกรณ์จำลอง Pressure Sensor จะตรวจจับข้อมูลการกดและส่งไปยัง ESP32 จากนั้น ESP32 จะส่งข้อมูลไปยัง Unity เพื่อประมวลผล ระบบจะแสดง Feedback เช่น จำนวนครั้งของการกด จังหวะการกด และสถานะการปฏิบัติผ่าน PICO 4 เมื่อจบการฝึก ระบบจะแสดงคะแนนและสรุปผลการฝึกของผู้ใช้งาน

วิธีการดำเนินงาน
ศึกษาหลักการ CPR และเทคโนโลยี PICO 4, Unity, ESP32 และ Pressure Sensor
กำหนดขอบเขตและออกแบบสถานการณ์จำลองสำหรับการฝึก
ออกแบบและประกอบอุปกรณ์จำลองหน้าอกพร้อม Pressure Sensor
พัฒนาโปรแกรม ESP32 สำหรับรับและตรวจจับข้อมูลจาก Sensor
พัฒนาสภาพแวดล้อม VR และ Scenario ด้วย Unity
พัฒนาระบบ Interaction และลำดับการฝึก CPR
เชื่อมต่อ ESP32 กับ Unity เพื่อรับข้อมูลจากการกดหน้าอก
พัฒนาระบบ Feedback และประเมินผลการฝึก
รวมระบบและทดสอบการทำงานบน PICO 4
ทดลองใช้งาน เก็บผลการทดสอบ และปรับปรุงระบบ
ด้านที่นำไปประยุกต์ใช้

โครงงานสามารถนำไปประยุกต์ใช้ใน ด้านการศึกษาและการฝึกอบรม (Education & Training) โดยใช้เป็นสื่อเสริมสำหรับการเรียนรู้และฝึกทักษะ CPR ในสถานศึกษา สถานที่ทำงาน หรือการฝึกอบรมด้านความปลอดภัย นอกจากนี้ยังสามารถต่อยอดเป็นระบบประเมินผลการฝึกที่จัดเก็บข้อมูลของผู้ใช้งานและแสดงผลผ่าน Dashboard ได้

ประโยชน์ที่คาดว่าจะได้รับ
ได้ต้นแบบระบบฝึก CPR ที่ผสมผสาน VR กับการปฏิบัติผ่านอุปกรณ์จริง
ผู้ใช้งานสามารถฝึกในสถานการณ์จำลองที่ปลอดภัยและสามารถฝึกซ้ำได้
สามารถตรวจจับและประเมินการกดหน้าอกด้วย Sensor และ Microcontroller
ผู้ใช้งานได้รับ Feedback และผลการฝึกแบบ Real-Time
เป็นการประยุกต์ใช้ความรู้ด้าน VR, Microcontroller, Sensor และ Software Development ในการพัฒนาระบบจริง
สามารถต่อยอดไปสู่ระบบฝึกอบรมและระบบติดตามผลสำหรับผู้สอนได้ในอนาคต
