================================================================================
คู่มือการทำงาน: VR 360/180 LIVE STREAMING ON PICO 4
================================================================================

[ขั้นตอนที่ 1: สิ่งที่ต้องดาวน์โหลดและติดตั้งในเครื่องคอมพิวเตอร์]
--------------------------------------------------------------------------------
1. ติดตั้ง Unity ผ่าน Unity Hub:
   - เวอร์ชันที่ใช้: Unity 6.3 LTS (รหัส 6000.3.21f1)
   - โมดูลที่ต้องติ๊ก (Add Modules):
     [✔] Android Build Support
     [✔] Android SDK & NDK Tools (กดลูกศรหน้า Android ลงมาเพื่อติ๊ก)
     [✔] OpenJDK (กดลูกศรหน้า Android ลงมาเพื่อติ๊ก)
   *หมายเหตุ: ถ้าไม่ลง SDK/NDK จะคอมไพล์โปรเจกต์ลงแว่น Pico 4 ไม่ได้เด็ดขาด*

2. ติดตั้ง Library ของ Python (เปิด CMD พิมพ์คำสั่งนี้):
   pip install flask opencv-python numpy
   หรือ
   python -m pip install flask opencv-python numpy
   หรือ
   py -m pip install flask opencv-python numpy


[ขั้นตอนที่ 2: วิธีเปิดโปรเจกต์จาก 3 โฟลเดอร์ (Assets, Packages, ProjectSettings)]
--------------------------------------------------------------------------------
วิธีที่ 1 (แนะนำที่สุด - เร็วและไม่เกิดไฟล์ชนกัน):
1. สร้างโฟลเดอร์ว่างขึ้นมา 1 โฟลเดอร์บนคอมพิวเตอร์ ตั้งชื่อว่า "CN360_Project"
2. นำ 3 โฟลเดอร์ที่ได้มา ได้แก่:
   - Assets
   - Packages
   - ProjectSettings
   มาวางลงในโฟลเดอร์ "CN360_Project" นี้
3. เปิดโปรแกรม Unity Hub
4. กดปุ่ม "Add" (หรือ "Add project from disk") ด้านบนขวา
5. คลิกเลือกโฟลเดอร์ "CN360_Project" แล้วกด Add Project
6. คลิกเปิดโปรเจกต์ขึ้นมา (Unity จะสร้างโฟลเดอร์แคช Library ของเครื่องใหม่ให้อัตโนมัติ รอโหลดประมาณ 3-5 นาที)

วิธีที่ 2 (กรณีเผลอกดสร้างโปรเจกต์ว่างใน Unity ไปก่อนแล้ว):
1. ปิดโปรแกรม Unity Editor ให้สนิทก่อน
2. เข้าไปในโฟลเดอร์โปรเจกต์นั้น ลบโฟลเดอร์ Assets, Packages, ProjectSettings เดิมทิ้ง
3. นำ 3 โฟลเดอร์ที่ได้รับมาวางทับลงไปแทนที่
4. เปิด Unity Hub แล้วเข้าโปรเจกต์ตามปกติ


[ขั้นตอนที่ 3: ตรวจสอบและทดสอบระบบบนคอมพิวเตอร์ก่อนออกเดินทาง]
--------------------------------------------------------------------------------
1. รันเซิร์ฟเวอร์จำลอง:
   - นำไฟล์ mock_server.py และ sample_360.mp4 มาวางไว้โฟลเดอร์เดียวกัน
   - เปิด Command Prompt แล้วพิมพ์: py mock_server.py
   - เซิร์ฟเวอร์จะเปิดพอร์ต 5000 และจำลองวิดีโอ 360 เล่นวนลูปตลอดเวลา
2. เปิด Scene ใน Unity:
   - ในหน้าต่าง Project ไปที่ Assets > Scenes > ดับเบิลคลิกเปิด "SampleScene"
3. กดปุ่ม Play (รูปสามเหลี่ยมด้านบน):
   - คลิกเมาส์ซ้ายหรือขวาค้างไว้ แล้วลากเมาส์: จะสามารถหมุนมองรอบตัว 360 องศาได้
   - กดปุ่มตัวเลขบนคีย์บอร์ดเพื่อทดสอบการตัดมุมมอง:
     * เลข 1 = Full 360 องศา
     * เลข 2 = ตัดมุมมอง 180 องศา (ด้านหน้า 0°)
     * เลข 3 = ตัดมุมมอง 180 องศา (ด้านขวา 90°)
     * เลข 4 = ตัดมุมมอง 180 องศา (ด้านหลัง 180°)
     * เลข 5 = ตัดมุมมอง 180 องศา (ด้านซ้าย 270°)
   - ตรวจสอบในหน้าจอ CMD ของ Python จะเห็นบรรทัดคำขอเปลี่ยนโหมดส่งเข้ามาตามปุ่มที่กด


[ขั้นตอนที่ 4: การตั้งค่าแว่น PICO 4 ให้พร้อมรับไฟล์]
--------------------------------------------------------------------------------
1. เปิดเครื่องและสวมแว่น Pico 4
2. ไปที่เมนู Settings > General > About
3. เลื่อนลงมาหาคำว่า "Software Version" แล้วใช้คอนโทรลเลอร์คลิกย้ำๆ 7-8 ครั้ง จนขึ้นแจ้งเตือนว่าเข้าสู่โหมดนักพัฒนาแล้ว
4. ที่แถบเมนูด้านซ้ายจะมีหัวข้อใหม่ชื่อ "Developer" โผล่ขึ้นมา ให้คลิกเข้าไปแล้วเปิดสวิตช์ "USB Debugging" ให้เป็น On
5. เสียบสาย USB-C ต่อจากแว่นเข้าคอมพิวเตอร์ สวมแว่นดูจะมีป็อปอัปถามว่า "Allow USB Debugging?" ให้ติ๊ก Always Allow แล้วกดยืนยัน


[ขั้นตอนที่ 5: ลำดับขั้นตอนการต่อและทดสอบ]
--------------------------------------------------------------------------------
ลำดับที่ 1: เครือข่าย (สำคัญที่สุด)
   - ห้ามใช้ Wi-Fi มหาวิทยาลัย (เช่น TU-WiFi, eduroam) เด็ดขาด เพราะระบบความปลอดภัยจะบล็อกไม่ให้อุปกรณ์คุยกัน
   - ให้เปิด Personal Hotspot จากโทรศัพท์มือถือ
   - นำ "คอมพิวเตอร์" และ "แว่น Pico 4" เชื่อมต่อเข้า Hotspot ของมือถือเครื่องเดียวกัน

ลำดับที่ 2: ฮาร์ดแวร์กล้อง 360 องศา
   - เสียบสาย USB ของกล้อง 360 เข้าโน้ตบุ๊ก
   - เปิดกล้องและตั้งค่าที่หน้าจอกล้องให้อยู่ในโหมด "Webcam" หรือ "UVC"
   - หากเป็นกล้องเฉพาะ (เช่น Insta360) ให้เปิดโปรแกรม Stitcher ของแบรนด์นั้นบนคอมทิ้งไว้เพื่อให้เย็บภาพกางแบนสด

ลำดับที่ 3: รัน Server Python
   - เปิด Command Prompt พิมพ์คำสั่ง: py mock_server.py
   - สังเกตข้อความบนหน้าจอ ถ้าเจอกล้องจริงจะขึ้น:
     "[INFO] ตรวจพบกล้อง 360 จริง! เริ่มดึงภาพสด..."
     (แต่ถ้าลืมเสียบกล้อง ระบบจะตัดไปเล่นคลิป sample_360.mp4 ให้เองอัตโนมัติ)

ลำดับที่ 4: ติดตั้งและเปิดแอปบนแว่น Pico 4
   - เสียบสาย USB-C จากคอมเข้าแว่น Pico 4
   - วิธีติดตั้งทำได้ 2 ทาง:
     ทางลัด A: ใช้โปรแกรม SideQuest ลากไฟล์ Live360_Pico.apk ลงแว่นได้เลย (เสร็จใน 10 วินาที)
     ทางตรง B: ใน Unity ไปที่ File > Build Settings > เลือก Android > ช่อง Run Device เลือกชื่อ Pico 4 แล้วกด "Build and Run"
     *ถ้ามีป็อปอัปสีเหลืองเตือนเรื่อง Input Handling is set to Both ให้กด "Ignore" ได้ทันที*

ลำดับที่ 5: เริ่มการสาธิต (Demo)
   - สวมแว่น Pico 4 เข้าไปที่ Library > Unknown Sources > เปิดแอปที่เพิ่งลง
   - ตัวแอปในแว่นจะดักฟังสัญญาณ UDP Beacon และล็อก IP คอมพิวเตอร์เองอัตโนมัติ (ไม่ต้องพิมพ์ IP เอง)
   - ภาพสดจากกล้องจะฉายโอบรอบตัวผู้สวมแว่นทันที
   - กดปุ่ม "Trigger (ไกปืนด้านหน้านิ้วชี้)" บนคอนโทรลเลอร์ Pico 4 เพื่อสลับโหมด 360° และ 180°


[คู่มือแก้ปัญหาฉุกเฉินหน้างาน (Troubleshooting Cheatsheet)]
--------------------------------------------------------------------------------
- ปัญหา: ภาพในแว่นเป็นสีดำสนิท
  วิธีแก้: 
  1. เช็คว่าคอมกับแว่นเกาะ Hotspot เดียวกันไหม
  2. ปิด Windows Defender Firewall บนคอมชั่วคราว เพื่อไม่ให้บล็อกพอร์ต 5000 และ 5005
  3. ใน Unity ตรวจสอบว่าใน Inspector ของ StreamManager มีการลาก StreamRenderTexture มาใส่หรือยัง

- ปัญหา: ภาพขึ้นช้า หรือกระตุก
  วิธีแก้: เปิดไฟล์ mock_server.py เลื่อนหาบรรทัด cv2.imencode แล้วแก้เลขคุณภาพ JPEG จาก 60 เหลือ 50 เพื่อให้ส่งข้อมูลผ่าน Wi-Fi ได้เร็วขึ้น

- ปัญหา: ภาพจากกล้องจริงขึ้นเป็นลูกตากลมๆ 2 ลูก (Dual Fisheye)
  วิธีแก้: กล้องไม่ได้เปิดโหมดเย็บภาพในตัว ให้เปิดโปรแกรมของค่ายกล้องนั้นขึ้นมาบน Windows เพื่อสั่ง Stitch ภาพสดก่อนส่งให้เว็บแคม
